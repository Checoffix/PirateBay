# PirateBay

Прототип 2D-платформера на Unity. Сделан упор на модульность: логика разбита на небольшие компоненты, а данные вынесены в ScriptableObject.

### Что реализовано:
- **Персонаж:** логика разбита на отдельные скрипты (`HeroMovement`, `HeroAttack`, `HeroDamageController`, `HeroInventory`). Реализованы перемещение, прыжки, скольжение по стенам, окно неуязвимости при получении урона.
- **Противники и ловушки:** патрулирование мобов (по точкам и границам платформ), стреляющие тотемы и ловушки. Несколько типов снарядов (прямой полет, по навесной дуге, по синусоиде).
- **Данные и конфиги:** настройки предметов и инвентаря лежат в `ScriptableObject`. Сделан кастомный `PropertyDrawer` для удобного выбора ID предметов в инспекторе.
- **Общие компоненты:** сенсоры окружения (проверка слоев через рейкасты и overlap-круги), система кулдаунов, спавнеры.

**Стек:** Unity, C#.
